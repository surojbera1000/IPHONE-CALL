# ভাষা / Language Rule

- এই প্রজেক্টে সবসময় **বাংলায়** (Bangla) উত্তর, ব্যাখ্যা ও সারাংশ দিতে হবে।
- টেকনিক্যাল শব্দ (APK, package name, command, permission, code) **ইংরেজিতেই** রাখা হবে — অনুবাদ করা হবে না।
- কোড, কমিট মেসেজ, ও ফাইলের কনটেন্ট স্বাভাবিক নিয়মেই (সাধারণত ইংরেজিতে) থাকবে; শুধু ব্যবহারকারীর সাথে চ্যাটের কথাবার্তা বাংলায় হবে।

---

# Language rule (English reference)

- Always reply to the user in **Bengali (Bangla)** for chat, explanations and summaries.
- Keep technical terms (APK, package names, commands, permissions, code) in English.
- Code, commit messages and file contents stay in their normal language (usually English); only the conversation with the user is in Bengali.
